Orbit jsDelivr edition — experimental, not browser-verified.
Target repository: Megatron963/Orbit, branch main.
1. Extract this ZIP.
2. In GitHub, choose Add file > Upload files.
3. Drag ALL FILES AND FOLDERS INSIDE the extracted folder into the repository root. Do not upload the ZIP or an extra enclosing folder.
4. Commit changes. Replace an older orbit.svg if prompted.
5. Open https://cdn.jsdelivr.net/gh/Megatron963/Orbit@main/orbit.svg
The SVG installs a repository-scoped service worker and opens an internally generated HTML shell. There is no redirect or iframe to the original Orbit host.
Do not change the GitHub username, repository, branch, or @main URL without rebuilding path prefixes.
The GitHub preview and downloaded local SVG are not the launch URL. Always use the jsDelivr URL above.
This edition defaults to Ultraviolet and Epoxy. Wisp is still an external relay. A browser/network that blocks workers or WebSockets may not run it.
Updates: jsDelivr caches repository files. Use jsDelivr Purge Cache for changed files and reload. Do not substitute a different branch/hash in the launch URL; paths are configured for @main.
Browser testing on jsDelivr is not completed. Report the exact startup error if it fails.
